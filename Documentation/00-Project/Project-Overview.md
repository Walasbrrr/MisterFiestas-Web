# Mister Fiestas

Proyecto web para presentar y comercializar servicios de organización de eventos
para clientes particulares y empresas.

## Estado actual

- Etapa digital: definición inicial / beta; el negocio ya está operando.
- Equipo: Walen, Sebastian, Mario y David.
- Primera implementación prevista: sitio web con Next.js.
- Evolución prevista: panel administrativo y API en fases posteriores.
- Estructura técnica propuesta: monorepo con `apps/`, paquetes compartidos y
  documentación del producto.

## Alcance inicial

- Servicios: decoración, DJ, animación, catering, photobooth, inflables, sonido e
  iluminación.
- Segmentos: cumpleaños, bodas, baby showers, gender reveals, graduaciones y
  eventos empresariales.
- Secciones: inicio, servicios, clientes, empresas, tienda, galería, nosotros y
  contacto.
- Experiencia deseada: entrada desde Google, propuesta clara, navegación visual,
  animaciones de scroll, fotos, precios/tienda y contacto.

## Contexto del negocio

- Mister Fiestas ya presta servicios actualmente.
- El sitio no necesita validar la existencia del negocio; su primera meta debe ser
  presentar la oferta real, generar confianza y convertir visitas en solicitudes de
  cotización.
- El catálogo, los precios, las fotografías, los testimonios y el proceso de
  atención deben levantarse desde la operación actual, sin inventar información.
