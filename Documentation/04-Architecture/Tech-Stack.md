# Tech Stack

## Frontend

- **Next.js 16**, App Router, **React 19** y **TypeScript**.
- **Tailwind CSS 4** y **shadcn/ui** sobre Radix UI.
- **Motion for React**, continuación actual de Framer Motion.
- **Lucide React**.
- **React Hook Form**, **Zod** y `@hookform/resolvers`.

## Backend y datos

- **Spring Boot** con **Java 21**.
- **Spring Security**, JWT y OAuth en una fase posterior.
- **Spring Data JPA**, **PostgreSQL** y **Flyway**.
- Contrato **OpenAPI / Swagger**.

## Servicios

- Cloudinary para imágenes y medios.
- Stripe para pagos internacionales.
- Azul o CardNET como opción para República Dominicana.
- Google Maps API.
- Google Analytics 4 y Google Search Console.
- Futuro: WhatsApp Business API, correo, panel administrativo, reservas e
  inventario.

## SEO

- Metadata API, Open Graph, sitemap, robots.txt y JSON-LD.

## Desarrollo y diseño

- pnpm, Git, GitHub, ESLint, Prettier, Husky y lint-staged.
- Figma y Excalidraw.

## Despliegue

- Frontend: Hostinger, confirmando que el plan soporte el runtime de Next.js usado.
- Backend: VPS mediante Docker.
- Base de datos: PostgreSQL con respaldos y acceso restringido.
