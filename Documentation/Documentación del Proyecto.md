# Plataforma Web MisterFiestas

## Resumen Ejecutivo

Este documento centraliza la información clave para el desarrollo de la página web de MisterFiestas. El objetivo principal es estructurar un catálogo digital que resalte los servicios más rentables y de mayor interés de venta, permitiendo a clientes particulares y corporativos (B2B) solicitar cotizaciones personalizadas de manera rápida y automatizada.

Toda la documentación detallada del proyecto se ha dividido en secciones específicas para facilitar su mantenimiento y lectura.
