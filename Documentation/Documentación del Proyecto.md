# Plataforma Web MisterFiestas

## Resumen ejecutivo

Landing page en **misterfiestas.com** que **recolecta información** del visitante
(fecha, servicios, datos de contacto) y la incluye en un **mensaje de WhatsApp
prellenado** para que el cliente solo pulse Enviar. Gratis (`wa.me`); sin e-commerce
ni backend en el MVP.

**Especificación del asistente:** [WhatsApp-Assistant.md](01-Product/WhatsApp-Assistant.md)  
**Quién hace qué:** [Responsibilities.md](03-Team/Responsibilities.md)

**Dominio oficial:** [misterfiestas.com](https://misterfiestas.com) · `https://misterfiestas.com`
