# Backend

Espacio reservado para la API de Mister Fiestas.

## Stack aprobado

- Java 21 y Spring Boot.
- Spring Security con JWT.
- Spring Data JPA.
- PostgreSQL y Flyway.
- OpenAPI / Swagger.
- Docker para el despliegue en VPS.

Antes de generar la aplicación se debe definir el primer contrato de API, las
entidades del dominio y las operaciones que realmente necesita el MVP. Los secretos
se configurarán mediante variables del entorno del VPS.
